# fonts

Font files (`.ttf` / `.otf`) the packs in `themes/` use, matched by **file name** (`"labelFont": {"file": "Orbitron.ttf"}`).

Font files are ignored by git (see `.gitignore`), so people following this repo get fonts from a download URL listed in the pack's `fonts` section, or from their own `/sdcard/TCP Themes/fonts/` folder. Only commit a font here if its license allows redistribution.
